A Node 22 standard-library program that writes exactly one letter — **D** — to `/output/entry.txt` for make.fun's "One Letter for Your Day" bounty.

> **D — Doomscrolling.** The day spent thumbing a glowing feed past midnight, refreshing a timeline that never ends. Vivid (one thumb, one screen, 2 a.m.), funny (the kind of day you repeat to a friend), and true (an honest report of a real day) — and D is the word's true initial.

## Run it

```sh
node main.ts
```
